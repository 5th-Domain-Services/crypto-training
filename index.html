Lesson plan

Purpose and learning objectives

This lab builds practical cryptocurrency tracing skills with free, public blockchain tools. It works as a standalone exercise or alongside an instructor-led briefing. By the end, you should be able to:

  1. Profile an address: balance, transaction count, totals, and first funding source.
  2. Explain how blocks link and how transactions move from the mempool into a block.
  3. Identify Bitcoin address types and recognize invalid or mistyped addresses.
  4. Read a transaction's inputs, outputs, and fee, and test change-address assumptions.
  5. Use wallet clustering and service labels, and state their limitations.
  6. Separate payments made during a ransomware incident from later, unrelated deposits, using the WannaCry case.
  7. Visualize a fund flow and compare commercial attribution against native-chain data.
  8. Identify fiat off-ramps and write a report that separates observation from inference.
Timing and activity map

Core path: about 61 minutes. All activities: about 83 minutes. Optional activities can be assigned as homework or for faster students.

Materials, requirements, and rules of engagement
  • Computer with a modern browser and internet access.
  • This lab file (works offline for navigation; the tools require internet).
  • No accounts, wallets, browser extensions, or downloads are required. Free registration on any tool is optional. Platforms may change the free features available with or without account registration at any time.
  • Use only the training addresses provided. These are public, historical, and widely published examples.
  • There is no need to connect a wallet, upload files, or send funds on any site.
  • These are open-source tools you can keep using after the lab; for live cases, follow your organization's tool-use and OPSEC policies.
